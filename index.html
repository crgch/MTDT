준비됨.

• PNG: tEXt / zTXt / iTXt / eXIf / tIME 청크 제거
• JPEG: EXIF/XMP(APP1), IPTC(APP13), Comment 제거
• WebP: EXIF/XMP 청크 제거
• 이미지 픽셀을 캔버스로 다시 그리지 않고 파일 구조에서 메타데이터만 제거합니다.
• 브라우저 안에서만 처리하며 외부 서버로 이미지를 업로드하지 않습니다.
• ZIP64는 지원하지 않으므로 4GB 초과 ZIP이나 65,535개 초과 파일은 피해주세요.
